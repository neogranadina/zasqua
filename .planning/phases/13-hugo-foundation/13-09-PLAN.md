<deliberate_divergences>
1. **`formatDate` filter → pre-computed `date_formatted` field.** Eleventy applies formatDate at template render; Hugo reads the pre-computed value from 13-02 enrichment. Output bytes identical.
2. **`splitPipe` filter → Hugo `split "|"`.** Both produce the same list semantics. Output HTML identical.
3. **`safeSlug` filter → identity.** Zasqua reference codes (entity codes, place codes, repository codes) are already URL-safe alphanumeric + hyphens. Omitted.
4. **`ui.levels[x] or x` fallback → `default x (index hugo.Data.ui.levels x)`.** Go template equivalent.
</deliberate_divergences>
