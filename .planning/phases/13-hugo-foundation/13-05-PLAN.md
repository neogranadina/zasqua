<deliberate_divergences>
Three adaptations are necessary because Eleventy and Hugo don't resolve certain things the same way. Each is documented here up front and must appear in the plan SUMMARY.

1. **CSS `<link>` path.** Eleventy: literal `<link rel="stylesheet" href="/css/main.css">`. Hugo: `{{ with resources.Get "css/main.css" | css.TailwindCSS $opts }}<link rel="stylesheet" href="{{ .RelPermalink }}">{{ end }}`. In dev mode the Hugo `.RelPermalink` resolves to `/css/main.css` (un-fingerprinted); in prod it resolves to `/css/main.HASH.css` plus an SRI integrity attribute. Rendered CSS content is identical. The `css.html` partial encapsulates this difference and baseof.html just calls `{{ partial "css.html" . }}`.

2. **`{{ site.description }}` fallback.** Eleventy: `<meta name="description" content="{{ description or site.description }}">` where `description` is the page-level var (if set) and `site.description` comes from `src/_data/site.js`. Hugo: `<meta name="description" content="{{ with .Params.description }}{{ . }}{{ else }}{{ site.Params.description }}{{ end }}">` after adding `description` to `[params]` in hugo.toml. Output bytes identical for equivalent data.

3. **Footer `{year}` substitution.** Eleventy: `{{ ui.footer.copyright | replace("{year}", site.buildYear) }}`, where `site.buildYear = new Date().getFullYear()` is a dynamic build-time value. Hugo: `{{ replace (index site.Data.ui.footer "copyright") "{year}" (now.Format "2006") }}` — `now.Format "2006"` computes the current year at build time. Output bytes identical. (Similarly, `{{ site.buildDate }}` becomes `{{ now.Format "2006-01-02" }}` — the same YYYY-MM-DD format Eleventy produces via `new Date().toISOString().split('T')[0]`.)

Any other divergence is a rejection condition — see <forbidden_patterns>.
</deliberate_divergences>

```gotmpl
{{/*

      <link rel="stylesheet" href="{{ .RelPermalink }}">
    {{ else }}
      {{ with . | fingerprint }}
        <link rel="stylesheet"
              href="{{ .RelPermalink }}"
              integrity="{{ .Data.Integrity }}"
              crossorigin="anonymous">
      {{ end }}
    {{ end }}
  {{ end }}
```


```gotmpl
{{/*
  Zasqua breadcrumb partial

  Port of src/_includes/breadcrumb.njk. Renders a breadcrumb trail with
  a hard-coded "Inicio" root (from ui.breadcrumb.home), followed by a
  `>` separator per intermediate crumb, then the current crumb — as
  link if crumb has a url, else as plain text.

  Context expected: `.breadcrumbs` — an array of `{title, url?}` objects.
  Invoke from page templates as:
    {{ partial "breadcrumb.html" (dict "breadcrumbs" .Params.breadcrumbs) }}

  Version: v1.0.0

        <span class="text-sm text-stone-500">{{ .title }}</span>
      {{ end }}

{{/* Version: v1.0.0 */}}
```
