<objective>
Add the Pagefind metadata hidden div at the top of layouts/descripcion/single.html and the OCR hidden indexing block at the bottom — the two remaining Eleventy-source blocks deferred from Plans 13-09 and 13-10.

These blocks are invisible to users but populate Pagefind's search index with filters (repository, level, year, country, ancestor, entidad, lugar), sort keys, and meta fields (reference_code, repository_code, date_expression, etc.).
</objective>

<interfaces>

<deliberate_divergences>
1. **`desc.date_start | extractYear`** → `substr .Params.date_start 0 4`. Eleventy's extractYear takes the first 4 chars of an ISO date (YYYY-MM-DD). Hugo equivalent: substring the first 4 characters of the date_start field. Byte-identical output for the well-formed dates produced by the data pipeline.

2. **`desc._entity_codes` / `desc._place_codes`** → derived inline via `range .Params.entity_links` (pulling `.code`) and `range .Params.place_links` (pulling `.place_code`). Same set of values emitted.

3. **`desc.ocr_text | escapeTemplate | safe`** → just `{{ . }}` inside the hidden div. Hugo's auto-escape in HTML body context already produces the correct &amp;/&lt;/&gt;/&quot; escapes that Nunjucks's escapeTemplate+safe combo produces; no extra filter needed.
</deliberate_divergences>
