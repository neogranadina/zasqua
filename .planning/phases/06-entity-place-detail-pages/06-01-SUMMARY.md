# Phase 6 Plan 01: Data Pipeline for Entity/Place Detail Pages Summary

**Reverse-lookup files, enriched data loaders (_linked_count, _entity_codes, _place_codes), Pagefind filter spans, and search.js URL parameter handling for entity/place scoped search**

## Performance

- **Duration:** ~8 min
- **Started:** 2026-03-27
- **Completed:** 2026-03-27
- **Tasks:** 2
- **Files modified:** 6

## Accomplishments
- precompute-links.js now generates desc-entity-lookup.json and desc-place-lookup.json reverse-lookup files from the already-loaded entity/place link arrays
- descriptions.js attaches `_entity_codes` and `_place_codes` to every description, with graceful handling when lookup files are absent
- entities.js and places.js attach `_linked_count` from their respective index files, with graceful handling when index files are absent
- description.njk emits hidden Pagefind filter spans for each entity/place code linked to a description
- search.js state, parseUrlParams, updateUrl, and search() all extended for entidad/lugar URL parameters

## Task Commits

1. **Task 1: Add reverse-lookup generation and enrich data loaders** - `6899929` (feat)
2. **Task 2: Add Pagefind filter spans and search.js URL parameters** - `d8f600f` (feat)

## Files Created/Modified
- `scripts/precompute-links.js` - Added step 5: builds entityCodesForDesc/placeCodesForDesc maps, writes desc-entity-lookup.json and desc-place-lookup.json; updated summary section with new counts
- `src/_data/descriptions.js` - Loads reverse-lookup files; attaches _entity_codes and _place_codes in enrichment loop
- `src/_data/entities.js` - Loads entity-index.json, builds countByCode map, attaches _linked_count to each entity
- `src/_data/places.js` - Loads place-index.json, builds countByCode map, attaches _linked_count to each place
- `src/description.njk` - Added two Nunjucks for-loops emitting Pagefind filter spans inside existing hidden div
- `src/js/search.js` - Extended state, parseUrlParams, updateUrl, and search() for entidad/lugar parameters

## Decisions Made
- Reverse lookups written as plain JSON objects (reference_code -> array of codes) — fast O(1) lookup in Node.js data loaders at build time
- entidad/lugar search filters are URL-only (not rendered as sidebar facets) — applied when arriving from detail page links, not from the sidebar
