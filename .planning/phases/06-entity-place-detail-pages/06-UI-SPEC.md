## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gaps, variant-tag internal padding gap |
| sm | 8px | Field-to-field spacing, authority link gap |
| md | 16px | Default element spacing, section padding |
| lg | 24px | Section-level padding, `desc-layout` gap (2rem) |
| xl | 32px | `detail-header` padding (2rem top/bottom) |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level padding |

Exceptions:
- Map embed height: **360px** (D-09 — fixed, not a spacing token)
- `desc-aside` width: **440px** (existing CSS — do not change)
- Touch targets on timeline links: minimum **44px** tall (mobile accessibility)
- `desc-layout` gap: **2rem (32px)** (existing CSS value — do not change)

**Source:** `src/css/input.css` `.detail-*` and `.desc-*` rules; D-09 from CONTEXT.md

## Typography

| Role | Size | Weight | Line Height | Font | Class |
|------|------|--------|-------------|------|-------|
| Body | 16px (1rem) | 400 (regular) | 1.6 | DM Sans | `font-sans` |
| Label / field label | 14px (0.875rem) | 600 (semibold) | 1.5 | DM Sans | `font-sans font-semibold` |
| Section heading | 13px (0.82rem) | 600 (semibold) | 1.2 | DM Sans, uppercase, `letter-spacing: 1px` | `font-sans font-semibold uppercase` |
| Page title / detail title | 28px (1.75rem) | 600 (semibold) | 1.3 | DM Sans | `font-sans font-semibold` |

Notes:
- Page titles use **DM Sans** (D-04 — no serif distinction from description pages)
- Section headers use **DM Sans uppercase** with 1px letter-spacing (D-06 — matching `.detail-section h3`)
- Field labels are **block** (label above value) — `.detail-label` pattern (D-07)
- Body text: `text-stone-600` on warm white background; field values: `text-stone-700`

**Source:** `src/css/input.css` `.detail-*` rules; CONTEXT.md D-04, D-06, D-07; `docs/frontend/guidelines/design-tokens.md`

## Interaction Contract

### Page Load Sequence

**Entity page:**
1. Nunjucks renders static HTML with all metadata from `entities.js` data
2. On `DOMContentLoaded`, `entity.js` fetches `/data/entity-links/{entity_code}.json`
3. Timeline renders from shard data — chronological entries, "Sin fecha" group at bottom
4. `linked_description_count` from shard updates the CTA link text

**Place page:**
1. Nunjucks renders static HTML with all metadata from `places.js` data
2. On `DOMContentLoaded`, `place.js` fetches `/data/place-links/{place_code}.json`
3. If `lat`/`lon` present: initialise MapLibre map at zoom 7 centred on coordinates; render burgundy pin marker; display coordinates below map
4. If no `lat`/`lon`: `.desc-notice` placeholder is already in HTML, no JS needed
5. Timeline renders below map (or standalone for no-coordinate pages)

### Timeline Overflow Handling

- Container: `max-height: 480px; overflow-y: auto`
- For entities/places with more than ~60 timeline entries, the container scrolls — no truncation, no pagination, no "show more" control on the detail page
- The CTA link to the search page handles the full filtered result set

### Map Configuration (MapLibre)

- Tile source: `pmtiles://https://tiles.zasqua.org/zasqua-places.pmtiles` (Phase 5 Worker)
- Initial zoom: 7 (country/region level for Colombian colonial archive context — D-10)
- Centre: `[lon, lat]` from place record
- Map style: Protomaps default light style (`https://cdn.protomaps.com/basemaps/v4/en.json`) — matches warm neutral palette
- Pin marker: 12px solid circle, `#8B2942` (burgundy), 2px white border — vanilla MapLibre `Marker`
- Map is not interactive for navigation (zoom/pan enabled by default; do not disable)
- MapLibre CSS + JS loaded from CDN in `{% block head %}` — only on `lugar.njk`

### Conditional Rendering Rules

- Name variants section: render only if `name_variants` is non-empty (D-02 pattern from description.njk)
- Dates of existence / history: render only if field is non-null (D-04)
- Authority links: render each pill individually with `{% if place.wikidata_id %}` — never an empty container (D-24)
- Map vs. notice: controlled by `{% if place.lat and place.lon %}` in Nunjucks — no JS branching needed
- Role label on timeline entries: only for entity pages (place timeline entries have no role)

## Page Structure Reference

### Entity Detail Page (`/entidad/{entity_code}/`)

```
<detail-header>
  breadcrumb: Inicio / Entidades / {display_name}
  <detail-title>  {display_name}  (DM Sans 600 1.75rem stone-900)
  <detail-meta>   <level-badge periwinkle>  {entity_type_label}
                  date_range if present

<detail-content>
  <desc-layout>

    <desc-metadata>  [left, max 728px]
      <detail-section> Identificación
        detail-field: Nombre
        detail-field: Nombre normalizado  (if surname/given name present)
        detail-field: Tipo
        detail-field: Fechas de existencia  (if present)
        detail-field: Función principal  (if present)
        detail-field: Variantes del nombre → .variant-tags  (if present)

      <detail-section> Historia  (if history present)
        detail-field: Historia

      <detail-section> Descripciones vinculadas
        <a href="/buscar/?entidad={code}" class="linked-desc-link">
          Ver las N descripciones vinculadas →

    <desc-aside>  [right, 440px]
      <detail-section> Apariciones en el archivo
        <div class="entity-timeline">
          [timeline entries — date, role, title link]
          [.timeline-no-date group at bottom]
```

### Place Detail Page (`/lugar/{display_name}/`)

```
<detail-header>
  breadcrumb: Inicio / Lugares / {display_name}
  <detail-title>  {display_name}  (DM Sans 600 1.75rem stone-900)
  <detail-meta>   <level-badge periwinkle>  {place_type_label}

<detail-content>
  <desc-layout>

    <desc-metadata>  [left, max 728px]
      <detail-section> Identificación
        detail-field: Nombre
        detail-field: Tipo
        detail-field: Variantes del nombre → .variant-tags  (if present)

      <detail-section> Identificadores externos  (if any authority ID present)
        <div class="authority-links">
          <a class="authority-pill"> Wikidata ↗  (if wikidata_id)
          <a class="authority-pill"> WHG ↗  (if whg_id)
          <span class="detail-field"> HGIS: {hgis_id}  (if hgis_id, plain text)

      <detail-section> Descripciones vinculadas
        <a href="/buscar/?lugar={code}" class="linked-desc-link">
          Ver las N descripciones vinculadas →

    <desc-aside>  [right, 440px]
      [IF lat/lon present]
        <div class="place-map" id="map-{place_code}"></div>
        <p class="place-map-coords">{lat}, {lon}</p>

      [IF no lat/lon]
        <div class="desc-notice">
          <span class="desc-notice-icon material-symbols-outlined">location_off</span>
          <p class="desc-notice-title">Ubicación no disponible</p>
          <p class="desc-notice-text">...</p>

      <detail-section> Apariciones en el archivo
        <div class="entity-timeline">  [same structure as entity timeline]
```
