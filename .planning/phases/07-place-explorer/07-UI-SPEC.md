## Interaction Contracts

### Page Load
- On init, fetch `/data/place-index.json` (~300 KB) and show `.search-loading` overlay
- Parse URL query params to restore state before first render
- After data loads: render sidebar facets, results list (page 1), and map with full heatmap

### Search Input
- Debounce: 200ms after last keystroke before filtering
- Match: case-insensitive substring on `display_name`
- Input field: inline below intro paragraph, above sidebar/map split, full container width on mobile
- On input change: reset to page 1, update URL, re-render list + map

### Facet Filters (sidebar)
- Three facet groups, all expanded by default:
  1. "Tipo de lugar" — checkboxes for types present in data only (city/7860, river/253, region/47, other/17); labels from `ui.place.types`
  2. "Coordenadas" — single checkbox: "Solo lugares con coordenadas" (maps `hasCoords: true`)
  3. "Autoridades" — single checkbox: "Solo con vínculos de autoridad" (maps `hasAuthority: true`)
- On change: update URL, reset to page 1, re-render list + map

### Filter Pills
- Shown between search input and results info bar
- One pill per active filter (type values each get their own pill)
- Clicking × on a pill removes that filter and re-renders
- "Clear all filters" button appears when any filter is active

### URL State
- Params: `q`, `type` (repeatable), `coords` (boolean), `authority` (boolean), `sort`, `page`, `mapBound`
- `pushState` on any filter/search change; `popstate` restores state

### Results List
- Default sort: alphabetical by `display_name`
- Sort toggle (top right of results info bar): "Nombre" | "Documentos" (descending by `linked_description_count`)
- Each result row: place name as `<a>` to `/lugar/{display_name}/`, place type badge, description count as "(N documentos)"
- 50 results per page; pagination below list

### Map — Heatmap Layer (`places-heat`)
- MapLibre source type: `geojson`, updated on every filter change
- Only places with coordinates (`lat` and `lon` present) contribute to heatmap/circle layers
- Heatmap visible z0–z9; fades out z9–z10 (`heatmap-opacity` interpolation)
- Circle layer (`places-circles`) fades in z8–z10; fully visible above z10
- Heatmap radius: interpolate z0→2px, z9→20px
- Heatmap intensity: interpolate z0→1, z9→2
- Circle radius: 5px; `--color-burgundy` fill, white stroke 1px
- Click on circle: MapLibre popup with place name + "Ver página" link to `/lugar/{name}/`
- Click at heatmap zoom: `map.flyTo()` zoom +3 to reveal individual points

### "Filter by map area" Toggle
- Default: OFF — map viewport has no effect on results list
- When ON: results list re-filters after every `moveend` event to places within `map.getBounds()`; URL param `mapBound=1`
- Toggle button positioned above map, right-aligned: inactive = stone-200 pill; active = burgundy-deep bg, white text
- Label: "Filtrar por área del mapa" (inactive) / "Filtrando por área del mapa" (active)

### Mobile Breakpoint (< 768px)
- Sidebar collapses; `.mobile-filter-toggle` button shown above map
- Clicking toggle reveals sidebar as a panel above map area
- Map and results list stack vertically below

### Basemap
- Protomaps `en.json` from `cdn.protomaps.com` — same style as lugar.njk detail pages
- Initial bounds: Colombia (`[-79.0, -4.2, -66.9, 13.4]`); zoom 5
