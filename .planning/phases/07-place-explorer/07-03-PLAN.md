  <files>src/explorar/lugares.njk, src/js/place-explorer.js</files>
  <action>
    Present the running /explorar/lugares/ page to the user for visual and functional verification. Run `npm run build:dev` if not already running and provide the local URL.
  </action>
  <what-built>
    Complete place explorer at /explorar/lugares/ with:
    - Search by place name (substring match, debounced)
    - Three facet filter groups (place type, coordinates, authority links)
    - Active filter pills with remove buttons
    - MapLibre heatmap at low zoom, individual points at high zoom
    - Clickable map points with popups linking to place detail pages
    - Paginated results list (50 per page) with sort toggle
    - "Filter by map area" toggle
    - URL state sync (shareable URLs, browser back/forward)
    - Mobile responsive layout
  </what-built>
  <how-to-verify>
    Run `npm run build:dev` and open http://localhost:8080/explorar/lugares/ (or relevant local dev URL).

    **1. Initial load**
    - Page shows loading state, then renders ~8,177 results
    - Map shows heatmap of all places with coordinates
    - Sidebar shows three facet groups, all expanded

    **2. Search (PEXP-01)**
    - Type "Tunja" — results filter to matching places
    - Map heatmap updates to show only matching places
    - Clear search — all results return

    **3. Facet filtering (PEXP-02)**
    - Check "Cuerpo de agua" in Tipo de lugar — only rivers shown (~253)
    - Check "Solo lugares con coordenadas" — only places with coords shown
    - Check "Solo con vinculos de autoridad" — further filtered
    - Confirm filter pills appear for each active filter
    - Click x on a pill — that filter removed
    - Click "Borrar todos los filtros" — all filters cleared

    **4. Map interaction (PEXP-03)**
    - At default zoom: heatmap visible (burgundy colour ramp)
    - Zoom in past z8-z10: heatmap fades, individual burgundy circle markers appear
    - Click a circle marker: popup shows place name + "Ver pagina" link
    - Click popup link: navigates to correct /lugar/{name}/ page
    - Click on heatmap area: map zooms in

    **5. Results list (PEXP-04)**
    - Each row shows: place name (link), type badge, description count
    - Click "Documentos" sort — highest counts first
    - Click "Nombre" sort — alphabetical
    - Pagination appears below results; click page 2 — results change
    - Click a result link — navigates to correct /lugar/{name}/ page

    **6. URL state**
    - Apply some filters, note the URL has query params
    - Copy URL, open in new tab — same state restored
    - Use browser back — previous state restored

    **7. "Filter by map area" toggle**
    - Click toggle — button changes to "Filtrando por area del mapa"
    - Pan/zoom map — results list updates to show only visible places
    - Click toggle again — full results restored

    **8. Mobile layout**
    - Resize browser to less than 768px width
    - Sidebar should be hidden; "Filtros" toggle button visible
    - Click toggle — sidebar appears
    - Map and results stack vertically

    **9. Empty state**
    - Type a nonsense search term (e.g. "zzzzz")
    - Should show "Sin resultados" message with "Borrar todos los filtros" button
