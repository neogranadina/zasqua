## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, remove-button padding inside pills |
| sm | 8px | Compact element spacing, pill padding (`0.25rem 0.5rem`) |
| md | 16px | Default element spacing, nav gaps |
| lg | 24px | Section padding, nav gap (`1.5rem`) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Container side padding: 15px (existing convention — do not change)
- Header height: 70px (`--header-height` layout constant — not a spacing token)
- Nav border-bottom hover underline: 2px (exact, for D-01 periwinkle underline)
- Border-radius on interactive elements: 50px (pill shape — shared visual language)

Source: RESEARCH.md + shared-visual-language.md + input.css `:root` block.

### 60/30/10 Distribution

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FAFAF9` (`--color-bg`) | Page background, header background, card surfaces |
| Secondary (30%) | `stone-50` / `stone-100` (`#F5F5F4` / `#FAFAF7`) | Facet panel background, input backgrounds, hover fills on secondary buttons |
| Accent (10%) | Burgundy `#8B2942` + Periwinkle `#C9D5FF` | See reserved-for list below |
| Destructive | none required | No destructive actions in this phase |

Accent reserved for:
- **Burgundy** (`#8B2942`): active/selected filter pills (D-07), masonry grid hover overlay at 0.85 opacity (D-06), link hover text colour globally (`a:hover`), footer background uses dark burgundy `#4A1522`
- **Deep Burgundy** (`#6B1F33`): primary action buttons (existing pattern — not changed in this phase)
- **Light Burgundy** (`#B14D66`): link hover text (`a:hover text-burgundy-light` — already in `@layer base`)
- **Periwinkle** (`#C9D5FF`): nav link hover/active underline (D-01), active pagination item background (D-08), level badges (already done in Phase 1)
- **Dark Burgundy** (`#4A1522`): footer background only (already done in Phase 1)

Neutrals (stone scale) for: body text (`stone-600`), headings (`stone-900`), borders (`stone-300`), muted labels (`stone-400`), secondary text (`stone-500`), facet label text (`stone-600`), unselected filter pills (`stone-900` bg).

Source: CONTEXT.md decisions D-01 through D-13, RESEARCH.md token map, design-tokens.md.

## Token Replacement Map

Hardcoded hex values remaining in `input.css` and their replacements:

| Hardcoded Value | Replace With | Notes |
|----------------|--------------|-------|
| `#1C1917` | `var(--color-stone-900)` or `@apply text-stone-900` | stone-900 canonical |
| `#dedede` | `var(--color-stone-300)` or `@apply border-stone-300` | borders, dividers |
| `#f0f0f0` | `var(--color-stone-100)` or `@apply border-stone-100` | light dividers |
| `#A8A29E` | `var(--color-stone-400)` or `@apply text-stone-400` | muted text |
| `#78716C` | `var(--color-stone-500)` or `@apply text-stone-500` | secondary body text |
| `#57534E` | `var(--color-stone-600)` or `@apply text-stone-600` | secondary labels |
| `#292524` | `var(--color-stone-900)` | stone-900 dark (existing pills) |
| `#F5F5F4` | `var(--color-stone-100)` | light grey backgrounds |
| `#ddd` | `var(--color-stone-300)` | borders (TIFY section also) |
| `#f8f8f8` | `var(--color-stone-50)` | light backgrounds |
| `rgba(107,31,51,0.85)` | `rgba(139, 41, 66, 0.85)` | masonry overlay — no token for rgba; keep raw |
| `rgba(107,31,51,0.5)` | keep raw value | selected-ancestor — no rgba token |
| `#b8c4f0` | keep as-is | level-badge border — no matching token |
| `#fff` / `#ffffff` | keep as-is or `white` | no token replacement needed for white |

Preferred replacement method inside `@layer components`:
- For `color` and `background-color` properties: use `@apply text-stone-N` / `@apply bg-stone-N` when available
- For `border-color` and `border` shorthand: use `var(--color-stone-N)` directly (shorthand `@apply` can conflict)
- Always preserve `!important` in TIFY section overrides
