# Phase 10.2: Explorer Parity - Context

**Gathered:** 2026-04-11
**Status:** Ready for planning

<domain>
## Phase Boundary

Bring the place explorer, place detail pages, and entity detail pages to parity with the Phase 10.1 entity explorer redesign — consistent layout, facet behavior, interaction patterns, and visual language across all explorer and detail surfaces. Three plans: place explorer parity + basemap fix (10.2-01), place detail page tooltips + basemap fix (10.2-02), entity detail page polish (10.2-03).

</domain>

<decisions>
## Implementation Decisions

### Place Explorer Layout
- **D-01:** Reuse the 10.1 entity explorer layout pattern: sidebar-left (filters + place index) with map filling the rest of the viewport. Not a 2-row layout — same sidebar + main-content structure as the entity explorer
- **D-02:** Selected place card space is always reserved in the sidebar (above or within the index area) — no shrinking/enlarging the map when a place is selected
- **D-03:** Include empty state with example places and viewport filter keyed to map bounds (matching 10.1 patterns)

### Selected Place Card (Explorer Sidebar)
- **D-04:** Card fields: place name + place_type, document count, authority IDs (TGN, WHG links when available), "Ver ficha" link to place detail page

### Protomaps Basemap
- **D-05:** Switch from openfreemap/liberty to Protomaps CDN (api.protomaps.com), Light style
- **D-06:** Strip the Light style to terrain-only: keep earth, water, boundaries, and place labels. Remove roads, buildings, POIs, and landuse layers. Pure physical geography + political boundaries basemap
- **D-07:** Apply consistently to both place explorer and place detail page maps

### Place Detail Page Map Tooltips
- **D-08:** Click-to-pin tooltips on map markers (close button to dismiss). No hover preview
- **D-09:** Tooltip fields: place name + place type only. Minimal content

### Entity Detail Page — Role Facet
- **D-10:** Replace current pill buttons (entity.js line 169+) with collapsible accordion using the 7-group role taxonomy from Phase 12.1/13
- **D-11:** All groups collapsed on load — user expands what they need
- **D-12:** Ungrouped/legacy roles go into an "Otros" bucket

### Entity Detail Page — Focal Node Colour
- **D-13:** Focal/home entity node in bipartite graph uses entity-type colour: burgundy for persons, periwinkle for corporate/family bodies

### Entity Detail Page — Cross-Navigation
- **D-14:** Dedicated "Ver en explorador" button in the entity info section, linking to `/explorar/entidades?entidad=ne-XXX`
- **D-15:** No deep-link in graph tooltips or headings — just the dedicated button

### Claude's Discretion
- Focal node colour implementation details (which colour tokens, how to detect entity type)
- Place explorer sidebar internal layout (filter section height, index scroll behaviour)
- Empty state example place selection
- Tooltip close button styling and positioning

</decisions>
