# Phase 10.2 Plan 01: Place Explorer Grid Layout and Protomaps Basemap Summary

Place explorer rewritten to match entity explorer's explorer-grid layout with Protomaps CDN Light terrain-only basemap, selected place card, empty state, and viewport filter toggle.

## What Was Built

**Task 1 — Template restructure**

`src/explorar/lugares.njk` was rewritten from a flat `container.font-sans` layout to the full `explorer-grid` structure used by `entidades.njk`:

- Row 1: `section.explorer-graph-panel` with `#explorer-map` canvas and `#map-empty-state.graph-empty-state` overlay; `aside.explorer-selected-col` with `#selected-place-card.selected-entity-card`
- Row 2: `aside.explorer-filters-col` with `#viewport-filter-toggle.viewport-filter-btn`, `#place-search-input`, `#sidebar-facets`; `div.explorer-results-col` with `#place-explorer` container
- `{% block head %}` loads MapLibre CSS+JS and `@protomaps/basemaps@5` CDN script
- `data-protomaps-key='{{ site.protomaps_key }}'` passes the key to JS

`src/_data/site.js` gained `protomaps_key: process.env.PROTOMAPS_KEY || "YOUR_KEY_HERE"`.

**Task 2 — PlaceExplorer rewrite**

`src/js/place-explorer.js` was rewritten with these key changes:

- `buildTerrainStyle()` — builds Protomaps terrain-only MapLibre style, filtering out `roads`, `transit`, `buildings`, `pois`, `landuse`, `landcover` source layers. Falls back to plain background if key is absent.
- `buildDOM()` — no longer builds the grid; injects search input into `#place-search-input`, results/pills/pagination into `#place-explorer`, facets into `#sidebar-facets`.
- `initMap()` — uses `buildTerrainStyle()` instead of openfreemap liberty style; container is the template-provided `#explorer-map`.
- `highlightPlace(place)` — populates `#selected-place-card` with name, type badge, doc count, TGN/WHG authority links, "Ver ficha" link; close button resets to stub; pans/zooms map to place coords.
- `initEmptyState()` — shows `#map-empty-state` on first load; wires 4 example buttons (Santa Fe de Bogotá, Cartagena de Indias, Quito, Popayán) via normalised slug matching.
- `initViewportFilter()` — wires `#viewport-filter-toggle` button with label toggle and `moveend` debounce.
- Map circle click calls `highlightPlace()` using `allPlaces` record for full authority data.
- Results list click also calls `highlightPlace()` for bidirectional map-list sync.
