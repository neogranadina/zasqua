## What Was Built

**Task 1 — Accordion role filter + focal node colour fix (`src/js/entity.js`)**

Added the `roleGroups` array (7 groups: Producción y menciones, Correspondencia, Atestación notarial, Procesos judiciales, Familia y sucesión, Transacciones, Materiales visuales) and a `groupedRoles` Set after `entityColors`. Replaced the old `buildRoleFilters` function — which built flat pill buttons and an inline explorer link — with a new function that:

- Counts roles from `allLinks`, builds visible groups (only those with at least one role present), collects ungrouped roles into an "Otros" bucket
- Renders using `focal-role-*` CSS classes (same as `entity-explorer.js`) so the accordion inherits all existing styles without new CSS
- All groups collapsed on initial load; a group auto-expands if any of its members are already in `activeRoles`
- Group header click toggles collapse; group checkbox controls all members (tri-state: all/some/none); individual checkboxes add/remove from `activeRoles`; "Limpiar" button visible only when filters are active
- Re-renders in place on every state change (calls `buildRoleFilters(allLinks)` after each `applyFilters()`)

Also replaced the broken `mappedType` ternary:
```javascript
// Before (bug: 'familia' falls through to 'person' → burgundy)
var mappedType = eType === 'persona' ? 'person' : eType === 'institución' ? 'corporate_body' : 'person';

// After (covers all three Spanish labels from ui.entity.types)
var TYPE_MAP = { 'persona': 'person', 'institución': 'corporate_body', 'entidad corporativa': 'corporate_body', 'familia': 'family' };
var mappedType = TYPE_MAP[eType] || 'person';
```

The old entry `eType === 'institución'` did not match the actual `.level-badge` text ("Entidad corporativa") — that case is now also covered.

**Task 2 — Ver en explorador button (`src/entidad.njk`)**

Replaced the `detail-field` wrapper containing the "Red de entidades" label + inline anchor with a self-descriptive burgundy CTA button. The button uses the same network-graph SVG icon as the graph toggle in the same template and Tailwind utility classes for styling (`bg-[#8B2942]`, hover darkens to `#6f2035`). URL is `/entidades/?entidad={{ ent.entity_code }}` — confirmed correct by the entity explorer's `?entidad=` param handling.
