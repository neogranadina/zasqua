# Phase 10.2 Plan 02: Place Detail Page Protomaps Basemap and Marker Tooltip Summary

Replaced the broken openfreemap basemap on place detail pages with the Protomaps CDN Light terrain-only style (earth, water, boundaries, labels — no roads, buildings, POIs) and added a click-to-pin tooltip showing place name and type, with close-button and pan-to-dismiss behaviour.

## What Was Built

**src/js/place.js** — Map init IIFE rewritten:
- Checks for `basemaps` global (from `@protomaps/basemaps@5` CDN script) before proceeding
- Reads `data-protomaps-key`, `data-place-name`, `data-place-type` from `#place-map` element
- Builds terrain-only style by filtering out `roads`, `transit`, `buildings`, `pois`, `landuse`, `landcover` source layers from the `light` Protomaps flavor
- Style uses Protomaps CDN tile URL (`api.protomaps.com/tiles/v4.json?key=...`)
- Marker gets `cursor: pointer` and a click listener
- Click opens a `.graph-tooltip.map-tooltip` div positioned above the marker via `map.project()`
- Tooltip contains a `×` close button (`.map-tooltip-close`) and place name + type content
- `dismissTooltip()` called on close button click and on `movestart` (map pan)
- `escapeHtml()` applied to all user-data strings before innerHTML (T-10.2-04)

**src/lugar.njk** — Template updates:
- `#place-map` div gains `data-place-name`, `data-place-type`, `data-protomaps-key` attributes
- Head block: PMTiles module import removed; `@protomaps/basemaps@5/dist/basemaps.js` CDN script added

**src/css/input.css** — New `.map-tooltip` and `.map-tooltip-close` classes added in `@layer components`, near existing `.graph-tooltip` styles. Uses oklch colour values matching project token convention.
