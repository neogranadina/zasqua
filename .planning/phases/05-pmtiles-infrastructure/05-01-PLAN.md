  <action>
Create `scripts/places-to-geojson.js` — a Node.js script (stdlib only, no npm dependencies) that:

1. Reads `data/places.json` via `fs.readFileSync`
2. Filters to places where both `lat` and `lon` are not null/undefined
3. Maps each place to a GeoJSON Feature with:
   - `type: "Feature"`
   - `geometry: { type: "Point", coordinates: [p.lon, p.lat] }` — CRITICAL: longitude first per GeoJSON spec (per D-05 and research Pitfall 4)
   - `properties: { place_code: p.place_code, display_name: p.display_name }` — only these two properties per D-05
4. Wraps in `{ type: "FeatureCollection", features }` and writes to `data/places.geojson`
5. Logs: number of features written, number of places skipped (no coordinates)

Match the coding style of `scripts/precompute-links.js` (shebang, strict mode, descriptive console output).

Coordinate validation: for Colombian archive places, longitude should be approximately -74 to -67 (negative) and latitude approximately 1-12 (positive). Log the first feature's coordinates so a human can spot-check.
  </action>

**worker-tiles/src/index.ts:**
Copy the Protomaps Cloudflare Worker source from `protomaps/PMTiles/serverless/cloudflare/src/index.ts` verbatim. This is the canonical implementation that handles:
- R2 range reads (HTTP 206 partial content)
- CORS headers with `Vary: Origin` (critical for Firefox/Safari per research Pitfall 1)
- Cache API integration (requires custom domain, not `*.workers.dev`)
- ETag-based conditional requests
- OPTIONS preflight handling

The Worker reads configuration from wrangler.toml vars: `ALLOWED_ORIGINS`, `CACHE_CONTROL`, `PMTILES_PATH`. The R2 bucket is bound as `BUCKET`.

Do NOT hand-roll Range request handling — use the Protomaps template as-is. The research explicitly warns against this (Don't Hand-Roll section).

To obtain the source, run:
```bash
npx -y degit protomaps/PMTiles/serverless/cloudflare worker-tiles-template
```
Then copy `worker-tiles-template/src/index.ts` to `worker-tiles/src/index.ts`. Discard the template directory after copying. If degit fails, fetch the raw file from GitHub:
```bash
curl -sL https://raw.githubusercontent.com/protomaps/PMTiles/main/serverless/cloudflare/src/index.ts -o worker-tiles/src/index.ts
```

After creating all files, run `cd worker-tiles && npm install` to generate `package-lock.json`.
