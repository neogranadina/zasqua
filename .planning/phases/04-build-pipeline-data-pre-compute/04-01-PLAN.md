Create `scripts/precompute-links.js` (CommonJS, `'use strict'`):

1. Read environment: `DATA_DIR` (default `path.join(__dirname, '..', 'data')`), `DEV_MODE`, `DEV_LIMIT` (default 500).

2. Read `entity_links.json` from DATA_DIR. Log record count. Group by `entity_code` into a Map. Each shard value is an array of `{ reference_code, title, date_expression, repository_code, role }`.

3. Write per-entity shards to `data/entity-links/{entity_code}.json`. Create directory with `fs.mkdirSync(shardsDir, { recursive: true })`. In DEV_MODE, limit to DEV_LIMIT shards. Log progress every 10,000 shards.

4. Read `entities.json` from DATA_DIR. Build `entity-index.json` (per D-06): each record has exactly these fields: `entity_code`, `display_name`, `sort_name`, `entity_type`, `date_earliest`, `date_latest`, `primary_function`, `linked_description_count`. The `linked_description_count` is the length of the entity's shard array (0 if no links). Write to `data/entity-index.json`. Log record count.

5. Read `place_links.json` from DATA_DIR. Log record count. Group by `place_code` into a Map. Each shard value is an array of `{ reference_code, title, date_expression, repository_code, role }`. Log warning for any link with null/undefined `place_code` and skip it.

6. Write per-place shards to `data/place-links/{place_code}.json`. Create directory. In DEV_MODE, limit to DEV_LIMIT shards. Log progress every 5,000 shards.

7. Read `places.json` from DATA_DIR. Build `place-index.json` (per D-07): each record has exactly these fields: `place_code`, `display_name`, `place_type`, `lat` (mapped from `p.latitude`), `lon` (mapped from `p.longitude`), `has_wikidata` (boolean: `!!p.wikidata_id`), `has_whg` (boolean: `!!p.whg_id`), `has_hgis` (boolean: `!!p.hgis_id`), `linked_description_count`. CRITICAL: rename `latitude` to `lat` and `longitude` to `lon` — the backend exports full field names but D-07 specifies short names. Write to `data/place-index.json`. Log record count.

8. Log summary: total entity shards, total place shards, entity-index records, place-index records.

Create `scripts/precompute-cooccurrence.js` (CommonJS, `'use strict'`):

1. Read environment: `DATA_DIR`, `COOCCURRENCE_MIN_WEIGHT` (default 3).

2. Read `entity_links.json` from DATA_DIR. Group by `reference_code` into a Map (each value is an array of entity_codes).

3. For each description with >= 2 unique entity_codes, emit all pairs. Use sorted order to ensure `source < target` lexically. Accumulate edge weights in a Map keyed by `${source}|${target}`.

4. Filter edges by minimum weight. Build node set from filtered edges only.

5. Read `entities.json` to get display_name and entity_type for each node. Build node array: `{ id, label (display_name), type (entity_type), count (total links from byEntity map) }`.

6. Write `data/entity-cooccurrence.json` with structure: `{ min_weight, generated_at (ISO string), node_count, edge_count, nodes, edges }`. Log node count, edge count, and file size.

Both scripts exit with code 1 on error via `.catch(err => { console.error(err); process.exit(1); })`.

```javascript
const fs = require('fs');
const path = require('path');

const DEV_MODE = process.env.DEV_MODE === 'true';
const DEV_LIMIT = 100;
const DATA_DIR = process.env.DATA_DIR || path.join(__dirname, '..', '..', 'data');

module.exports = async function() {
  const filePath = path.join(DATA_DIR, 'entities.json');
  console.log(`[entities] Reading ${filePath}`);
  const raw = fs.readFileSync(filePath, 'utf8');
  let entities = JSON.parse(raw);
  if (DEV_MODE && entities.length > DEV_LIMIT) {
    console.log(`[entities] DEV_MODE: Limiting to ${DEV_LIMIT} of ${entities.length}`);
    entities = entities.slice(0, DEV_LIMIT);
  }
  console.log(`[entities] Loaded ${entities.length} entities`);
  return entities;
};
```
