## Layout Contract

### Viewport-Filling App Shell

This page departs from the standard scrollable page layout. It is a full-viewport application.

```
[breadcrumb — full width, ~40px height, bg-stone-100]
[explorer-app — height: calc(100vh - 70px - breadcrumb-height), overflow: hidden]
  [explorer-sidebar — 320px fixed width, flex-col, border-right: stone-200]
    [explorer-sidebar-filters — flex-shrink: 0, padding: 12px sm, border-bottom: stone-200]
      [sidebar title "Explorar entidades" — 14px/600]
      [role filter pills — .entity-role-btn pattern, flex-wrap, gap: 6px]
      [facet section — entity type, function, date range — .facet-group pattern]
    [explorer-sidebar-index — flex: 1, overflow-y: auto, padding: 8px sm]
      [focal entity card — shown when entity focused via graph, fixed at top of index]
      [search input — existing Pagefind entity search]
      [result list — paginated, .entity-result items]
  [explorer-graph — flex: 1, min-width: 0, position: relative]
    [force-graph canvas — fills 100% of parent]
    [graph legend — inside frame, bottom-left, .graph-legend pattern]
    [tooltip — absolute positioned, .graph-tooltip, z-index: 100]
```

## Interaction Contract

### Node States and Transitions

All animations use CSS opacity/scale transitions via `nodeCanvasObjectMode`. The following timings apply:

| Transition | Duration | Easing |
|------------|----------|--------|
| Node fade-out (filter applied) | 150ms | ease-out |
| Node fade-in (filter restored) | 200ms | ease-in |
| Node add (new shard loaded) | `d3ReheatSimulation()` — physics-driven, no CSS | — |
| Tooltip appear | instant (no animation) | — |
| Tooltip dismiss | instant | — |

Source: CONTEXT.md D-10; RESEARCH.md Anti-Patterns; entity.js hover pattern (lines 303–426).

### Graph Simulation Parameters

| Parameter | Value | Source |
|-----------|-------|--------|
| `d3AlphaDecay` | 0.02 | CONTEXT.md D-41 |
| `d3VelocityDecay` | 0.3 | CONTEXT.md D-41 |
| charge strength | -20 | CONTEXT.md D-41 |
| link distance | 20 | CONTEXT.md D-41 |
| link strength | 0.5 | RESEARCH.md Pattern 2 |
| `cooldownTime` | omit entirely | CONTEXT.md D-40 |
| `onEngineStop` | omit entirely | CONTEXT.md D-40 |
| Initial zoom | `zoomToFit(0, 30)` after 300ms on first load only | RESEARCH.md Anti-Patterns |

### Hover Behaviour

- Hover over any node: highlight node and its immediate neighbours; dim all other nodes (opacity ~0.15 for dimmed).
- Move away: restore all nodes to full opacity.
- Source: entity.js hover pattern (D-29).

### Node Labels

- Labels rendered on canvas, visible only when: (a) node is hovered, or (b) global zoom scale > 1.2.
- Font: DM Sans, ~12px canvas units.
- Source: CONTEXT.md D-30; entity.js `globalScale > 1.2` check.

### Drag

- Drag enabled. On `onNodeDragEnd`: pin node by setting `node.fx = node.x; node.fy = node.y`.
- Source: CONTEXT.md D-43.

### Tooltip Positioning

- Positioned absolutely within `.explorer-graph` using `graphInstance.graph2ScreenCoords(node.x, node.y)`.
- Offset from node centre: +12px x, -8px y to avoid overlap with node.
- z-index: 100 (from `.graph-tooltip`).
- Max-width: 300px (from `.graph-tooltip`).
- Dismiss on click outside tooltip or on empty canvas.
- Source: RESEARCH.md "Don't Hand-Roll" table; `input.css` line 3000, 3008.

### URL State

- URL parameter: `?entidad=ne-12345` (not `?nodo=`). Updates on every entity refocus via `history.pushState`.
- Back button navigates graph history.
- Source: CONTEXT.md D-18, D-19 (Claude's Discretion resolved: `?entidad=` matches the entity page deep-link parameter from Phase 10).

## Focal Entity Card

When a user refocuses on an entity (either by clicking it in the graph or selecting it from the index), a card appears at the top of the sidebar index panel. This is the only "selected state" UI — no modal, no overlay.

Card content:
1. Entity name — 14px/600, DM Sans, stone-900
2. Entity type badge — `.entity-type-badge` (burgundy pill, white text, 14px/600)
3. Date range — 12px/400, stone-500
4. Document count — "{N} documentos vinculados" — 12px/400, stone-400

Card container: bg-stone-50, border: 1px solid stone-200, border-radius: 4px, padding: 8px 12px (sm), margin-bottom: 8px (sm).

Source: CONTEXT.md D-13; existing `.entity-type-badge`, `.entity-result-function`, `.entity-result-doccount` patterns in `input.css`.
