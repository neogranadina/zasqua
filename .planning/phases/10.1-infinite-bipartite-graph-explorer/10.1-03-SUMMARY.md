One-liner: EntityExplorer adapted with role filter pills from Pagefind data, focal entity card, and onEntitySelected/onFilterChanged callback hooks; entidades.njk wiring script connects both classes for full bidirectional graph-sidebar sync covering D-07 through D-19.

## What Was Built

### Task 1: EntityExplorer Adaptation

**Module-level constants added:**
- `roleLabels` — 28-entry role → Spanish label map (same as entity.js and infinite-bipartite-explorer.js)
- `entityColors` — entity type → hex colour map

**New state and callbacks:**
- `this.state.role = []` — active role filter array, synced to URL via `rol` param
- `this.activeRoles = new Set()` — role pill toggle state
- `this.onEntitySelected = null` — callback fired when user clicks result item (fires with entity code)
- `this.onFilterChanged = null` — callback fired after every search() with `{roles, entityTypes, functions, searchQuery}` object

**`renderRoleFilters(containerEl)` method:**
- Reads available roles from `this.globalFilters.role` (Pagefind global filter counts)
- Sorts by count descending
- Creates `entity-role-btn` buttons with Spanish labels and count badges
- Click handler toggles `activeRoles` Set, updates `state.role`, calls `search()`

**`renderSidebarFacets(containerEl)` method:**
- Renders entity_type, primary_function, and date facet groups into the `#sidebar-facets` container
- Uses global Pagefind filters (not scoped to current search) for consistent counts
- Delegates to existing `renderFacetGroup()` and `renderDateTree()` methods

**`highlightEntity(entityCode, entityMeta)` method (D-13):**
- Renders focal entity card in `#focal-entity-card` with name, entity-type-badge, date range, and doc count
- Searches current result list for entity; if found, adds `graph-focused` class and scrolls to it
- If not found, clears filters and searches for entity code to bring it into view

**`clearFocalCard()` method:**
- Clears `#focal-entity-card` innerHTML

**`renderResultCard()` modified:**
- Item div gets `cursor:pointer` and click handler that extracts entity code from URL regex (`/entidad/{code}/`)
- Fires `onEntitySelected(entityCode)` when clicked (D-14)
- Link's own click handler calls `stopPropagation()` only when `onEntitySelected` is wired, preserving normal navigation when standalone

**`search()` modified:**
- Adds `pfFilters.role = this.state.role` to Pagefind query when roles are active
- After rendering results, fires `onFilterChanged({roles, entityTypes, functions, searchQuery})`

**`init()` modified:**
- After Pagefind initialisation, calls `renderRoleFilters(document.getElementById('role-filters'))` and `renderSidebarFacets(document.getElementById('sidebar-facets'))`

**URL state:**
- `parseUrlParams()` reads `rol` param into `state.role` and syncs `activeRoles` Set
- `updateUrl()` appends `rol` params when active roles exist

**DOMContentLoaded block removed:**
- Wiring script now owns instantiation and initialization order

### Task 2: Bidirectional Wiring

**entidades.njk `{% block scripts %}` replaced** with IIFE wiring script:
- Instantiates `new InfiniteBipartiteExplorer(graphContainer)` and `new EntityExplorer(sidebarContainer)`
- `graph.onEntityFocused = fn` → calls `sidebar.highlightEntity(entityCode, entityMeta)` (D-13)
- `sidebar.onEntitySelected = fn` → calls `graph.refocusOn(entityCode)` (D-14)
- `sidebar.onFilterChanged = fn` → calls `graph.applyFilters(filters)` (D-08, D-09, D-15)
- `graph.init()` called first for immediate render
- `sidebar.init()` called next — Pagefind WASM loads asynchronously without blocking graph paint

**Decision decisions implemented:**
- D-13: Graph→Index sync via `onEntityFocused` → `highlightEntity`
- D-14: Index→Graph sync via `onEntitySelected` → `refocusOn`
- D-08, D-09: Unified filter propagation via `onFilterChanged` → `applyFilters`
- D-15: Search query included in filter object passed to graph
- D-16: Clicking unloaded entity in sidebar fires `onEntitySelected` → `refocusOn` loads it
- D-17: Clearing sidebar filters fires `onFilterChanged` with empty Sets → `applyFilters` clears graph
- D-18, D-19: URL state handled inside `refocusOn` and `init` in the graph class
