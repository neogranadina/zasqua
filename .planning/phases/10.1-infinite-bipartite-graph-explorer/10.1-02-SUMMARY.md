## What Was Built

### Task 1: Foundation

**Class structure** — IIFE wrapping `InfiniteBipartiteExplorer` constructor with prototype methods. Exposed as `window.InfiniteBipartiteExplorer`.

**State properties:**
- `graphNodes` Map, `graphEdges` Array, `nodeNeighbours` Map, `nodeLinks` Map — graph topology
- `shardCache` Map — entity-link shard cache (entityCode → links)
- `descLookup` Map — desc-entity-lookup.json loaded at init (refCode → [entityCodes])
- `entityMeta` Map — entity metadata cache (avoids repeated HTML fetches)
- `focalEntityCode`, `hopDistance` Map, `hoveredNode`, `selectedNode` — runtime state
- `onEntityFocused`, `onFiltersNeeded` — callback hooks for Plan 04 sidebar wiring

**`init()` method** — async: loads desc-entity-lookup.json, determines starting entity (URL ?entidad= override > curated-entity-graph.json nodes[0].id > DEFAULT_ENTITY ne-69501), calls initGraph(), loadEntity(), zoomToFit(400,30) after 300ms, renderLegend(), and adds popstate listener.

**`initGraph()` method** — creates ForceGraph with `.d3AlphaDecay(0.02)`, `.d3VelocityDecay(0.3)`, NO cooldownTime or onEngineStop (D-40), charge strength -20, link distance 20 / strength 0.5, ResizeObserver for responsive sizing.

**`drawNode()` canvas renderer:**
- Entity: filled circle, size `Math.max(3, Math.min(12, sqrt(linked_count)*1.5))`, colour from entityColors, label at zoom > 1.2 or hover
- Document — three states: terminal (hollow stroke, r=2), expandable (filled, r=2.5), expanded (larger filled, r=4)
- Overflow: dashed border circle with "+N documentos" text
- Hover dimming: opacity 0.15 for non-highlighted nodes

**Tooltips:**
- Entity tooltip: type badge, name, code, doc count, "Ver ficha completa" link
- Document tooltip: date, role, title, ref code, "Desplegar" button, "Ver descripcion" link

**`loadEntity()` method** — async: fetches shard, sorts by date descending, caps at 30, creates entity + doc nodes with expandability set from descLookup, creates overflow node if shard.length > 30, calls addNodesToGraph.

**`addNodesToGraph()` — incremental addition:** deduplicates by id/edge key, positions new nodes near anchor, updates graphInstance.graphData() + d3ReheatSimulation().

### Task 2: Navigation and Interaction

**`expandDocument()` method (D-27, D-34):**
- Gets entity codes from descLookup, filters out existing graph nodes
- Caps at MAX_EXPAND_ENTITIES (15) with hiddenEntityCount tracking
- Batch-fetches entity metadata via `Promise.all` (HTML page parsing)
- Marks document as `expanded = true` (triggers larger filled circle in drawNode)
- Adds new entity nodes + edges, recomputes hop distances, fires onEntityFocused

**`refocusOn()` method (D-28, D-37, D-38):**
- Calls pruneDistantNodes first
- Fetches entity shard (cache-first), creates doc nodes with expandability
- Creates/updates overflow node if needed
- Calls `history.pushState({entidad: code}, '', '?entidad=' + code)`
- Pans to entity node via graphInstance.centerAt()
- Fires onEntityFocused callback for sidebar sync

**`pruneDistantNodes()` method (D-36):**
- Runs BFS from focal entity, collects nodes > 3 hops or unreachable
- Also prunes overflow nodes whose parent is being pruned
- Removes from graphNodes Map, graphEdges array, and graphInstance.graphData() in one pass
- Reheats simulation, rebuilds adjacency

**`computeHopDistances()` method:**
- BFS from focalEntityCode over nodeNeighbours
- Stores result in `this.hopDistance` Map

**`loadMoreDocs()` method (D-35):**
- Slices next batch from cached shard at nextBatchOffset
- Creates doc nodes with expandability checks
- Updates overflow node count/label, removes overflow when hiddenCount ≤ 0
- Adds new doc nodes via addNodesToGraph

**`applyFilters()` method (D-10):**
- Two-pass visibility: entity nodes checked against entityTypes, searchQuery, roles (via edge scan); document nodes visible if any connected entity is visible
- Sets `_visible` flag; drawNode returns early for invisible nodes
- Reheats simulation after filter change

**`clearFilters()` method (D-17):**
- Sets `_visible = true` for all nodes, reheats simulation

**`popstate` handler:**
- Calls `refocusOn(e.state.entidad)` on back/forward navigation
