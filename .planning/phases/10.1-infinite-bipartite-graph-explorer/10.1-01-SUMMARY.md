## What Was Built

### Task 1: Data Pipeline Alignment

**build.sh** — Replaced single `npx pagefind --site _site` with three passes matching CI:
- Run 1: Description index (`pagefind/`) excluding entity/place pages
- Run 2: Entity explorer index (`pagefind-entities/`) globbing `entidad/**/*.html`
- Run 3: Place explorer index (`pagefind-places/`) globbing `lugar/**/*.html`
- Removed the co-occurrence precompute step (script already deleted in prior phase)

**scripts/precompute-links.js** — Added role computation before building entity-index:
- Iterates `entityLinks` to build a `Map<entity_code, Set<role>>` 
- Adds `roles: Array.from(entityRoles.get(e.entity_code) || [])` to each entity-index record
- Enables role-based Pagefind faceting for all 83K entities

**src/entidad.njk** — Two changes:
- Added role filter spans inside the hidden Pagefind metadata block: `{% for r in ent.roles %}<span data-pagefind-filter="role">{{ r }}</span>{% endfor %}`
- Updated deep-link URL from `?nodo={{ ent.entity_code }}` to `?entidad={{ ent.entity_code }}` (per D-18)

**Dead code removed:**
- `src/js/curated-entity-graph.js` — deleted (replaced by infinite-bipartite-explorer.js in Plan 02)
- `scripts/precompute-curated-graph.js` — deleted (curated graph no longer generated)
- `data/curated-entity-graph.json` — kept as static artefact for default entity lookup (degree data)

### Task 2: Viewport-Filling Template Shell and CSS
