Replace the existing minimal script block with:

```html
{% block scripts %}
  <script src="/js/infinite-bipartite-explorer.js"></script>
  <script src="/js/entity-explorer.js"></script>
  <script>
    (function() {
      'use strict';

      var graphContainer = document.getElementById('graph-container');
      var sidebarContainer = document.getElementById('entity-explorer');

      var graph = new InfiniteBipartiteExplorer(graphContainer);
      var sidebar = new EntityExplorer(sidebarContainer);

      // D-13: Graph -> Sidebar: when graph refocuses on entity, update sidebar
      graph.onEntityFocused = function(entityCode, entityMeta) {
        sidebar.highlightEntity(entityCode, entityMeta);
      };

      // D-14: Sidebar -> Graph: when user clicks entity in sidebar, load in graph
      sidebar.onEntitySelected = function(entityCode) {
        graph.refocusOn(entityCode);
      };

      // D-08, D-09, D-15: Sidebar -> Graph: when filters/search change, filter graph
      sidebar.onFilterChanged = function(filters) {
        graph.applyFilters(filters);
      };

      // Initialise both — graph first (renders immediately), sidebar async (Pagefind WASM)
      graph.init();
      sidebar.init();
    })();
  </script>
{% endblock %}
```

This wiring implements:
- **D-13 (Graph->Index):** `graph.onEntityFocused` calls `sidebar.highlightEntity` to show focal card and scroll to entity in results
- **D-14 (Index->Graph):** `sidebar.onEntitySelected` calls `graph.refocusOn` to load entity in graph
- **D-08, D-09 (Unified filtering):** `sidebar.onFilterChanged` calls `graph.applyFilters` so facets and role pills filter both graph and index
- **D-15 (Search->Graph):** Search query is included in the filters object passed to `graph.applyFilters`, which hides non-matching graph nodes
- **D-16 (Unloaded matches):** Sidebar shows all Pagefind matches; graph only filters the loaded subset. Clicking an unloaded match fires `onEntitySelected` which calls `graph.refocusOn` to load it.
- **D-17 (Clear filters):** Clearing filters in sidebar fires `onFilterChanged` with empty filter sets, which calls `graph.clearFilters` to restore all nodes
- **D-18, D-19 (URL state):** Handled inside `graph.refocusOn` (pushState) and `graph.init` (read ?entidad= on load). popstate handler in graph class restores history.

The graph initialises first to start rendering immediately. The sidebar's Pagefind WASM init runs asynchronously without blocking the graph paint (per RESEARCH Pitfall 4).
