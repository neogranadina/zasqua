  </read_first>
  <action>
Build the site locally using Eleventy (not the full build.sh which downloads data from B2):

```bash
npx eleventy
```

If entity data is already present in `data/` from a previous build, Eleventy should pick it up. If data is missing, the build will fail — in that case, run the precompute step first:

```bash
node scripts/precompute-links.js
npx eleventy
```

After Eleventy completes, run the three-index Pagefind build (from the updated build.sh pattern):

```bash
npx pagefind --site _site --output-subdir pagefind \
  --exclude-selectors "[data-pagefind-entity-page],[data-pagefind-place-page]"
npx pagefind --site _site --output-subdir pagefind-entities \
  --glob "entidad/**/*.html"
npx pagefind --site _site --output-subdir pagefind-places \
  --glob "lugar/**/*.html"
```

Start a local server:

```bash
npx http-server _site -p 8080
```

Report the local URL: `http://localhost:8080/entidades/`

<task type="checkpoint:human-verify" gate="blocking">
  <name>Task 2: Visual and functional verification of infinite bipartite graph explorer</name>
  <files></files>
  <action>
Present the running application to the user for verification against all 7 success criteria. The what-built and how-to-verify sections below describe the checkpoint.
  </action>
  <what-built>
Complete infinite bipartite graph explorer replacing the curated 100-node graph. The entity explorer page now has:
- Viewport-filling layout with sidebar (filters + entity index) and graph panel
- Infinite entity-document-entity chain navigation via click-to-expand
- Role filter pills, entity type/function facets, and search — all filtering both graph and sidebar
- Bidirectional sync: graph selection updates sidebar, sidebar selection loads in graph
- URL state with back-button navigation
- Smooth continuous simulation (no jarring stops or auto-zoom)
  </what-built>
  <how-to-verify>
Open `http://localhost:8080/entidades/` in the browser and verify all 7 success criteria:

**SC-1: Graph-dominant layout**
1. Verify the graph fills ~68% of the viewport width
2. Verify the sidebar is ~320px on the left with filters at top and entity index below
3. Verify no page-level scrollbar — the app fills the viewport from breadcrumb to bottom
4. Verify the breadcrumb is visible at the top

**SC-2: Initial load**
5. Verify one entity node (ne-69501 by default) and its document nodes appear
6. Verify document nodes are stone-coloured small dots
7. Verify the entity node is coloured by type (likely purple for corporate body)

**SC-3: Infinite chain navigation**
8. Hover over a document node — verify tooltip with date, role, title, ref code, "Desplegar" button, and "Ver descripcion" link
9. Click "Desplegar" on a document — verify new entity nodes appear
10. Click a non-focal entity node — verify it refocuses (loads its documents, old distant nodes disappear)
11. Repeat at least 3 times to confirm infinite navigation works

**SC-4: Smooth simulation**
12. Verify no jarring zoom or sudden jumps when nodes are added
13. Verify the simulation stays alive (nodes gently float) — not frozen after 15 seconds
14. Drag a node — verify it pins in place

**SC-5: Role filter pills**
15. Verify role pills appear in the sidebar filter section
16. Click a role pill — verify graph edges of that role become visible/hidden AND sidebar results update

**SC-6: Entity index**
17. Type an entity name in the search box — verify results appear with pagination
18. Verify entity type and function facets work

**SC-7: Graph-sidebar sync**
19. Click an entity in the graph — verify a focal entity card appears at the top of the sidebar
20. Click an entity in the sidebar results — verify the graph loads/pans to that entity
21. Check the URL bar — verify it updates to `?entidad=ne-XXXXX` on refocus
22. Press the back button — verify the previous entity state restores
  </how-to-verify>
