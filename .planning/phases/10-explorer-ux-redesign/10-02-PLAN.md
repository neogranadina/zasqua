  <action>
Create `scripts/precompute-curated-graph.js` that produces `data/curated-entity-graph.json`. The script combines the degree-selection pattern from `precompute-bipartite-graph.js` with the ForceAtlas2 layout from `precompute-cooccurrence.js`.

**Environment variables:**
- `DATA_DIR` — defaults to `path.join(__dirname, '..', 'data')`
- `CURATED_TOP_N` — defaults to `100`
- `CURATED_MIN_WEIGHT` — defaults to `2` (minimum co-occurrence edge weight to include)

**Algorithm:**
1. Read `data/entity_links.json` (array of `{ entity_code, reference_code, role }`)
2. Read `data/entities.json` (array of `{ entity_code, display_name, entity_type, ... }`)
3. Build `entityMeta` Map from entities.json: `entity_code -> { display_name, entity_type }`
4. Group entity_links by `reference_code` into a `byDoc` Map
5. Count co-occurrence degree per entity: for each document with 2+ unique entity codes, increment each entity's degree by (unique_count - 1). Use the same pattern as `precompute-bipartite-graph.js` lines 48-55
6. Sort entities by degree descending, take top `CURATED_TOP_N`. Store as `topSet` (Set of entity_codes)
7. Build co-occurrence edges between top entities only: for each document, find pairs of top entities that co-occur, accumulate edge weight. Use edge key `[min(a,b), max(a,b)].join('|')` for deduplication (same pattern as precompute-cooccurrence.js)
8. Filter edges: keep only edges with weight >= `CURATED_MIN_WEIGHT`
9. Build a graphology `Graph` (undirected): add nodes with `{ label, type, degree }`, add edges with `{ weight }`
10. Run `forceAtlas2.assign(graph, { iterations: 500, settings: { gravity: 1, scalingRatio: 10, barnesHutOptimize: true } })`
11. Extract node positions: for each node, read `graph.getNodeAttributes(node).x` and `.y`. Store as both `x`/`y` AND `fx`/`fy` on the node object (so force-graph treats them as pinned — per research pitfall #2)
12. Write `data/curated-entity-graph.json`:

```json
{
  "generated_at": "ISO8601",
  "top_n": 100,
  "node_count": N,
  "edge_count": M,
  "nodes": [
    { "id": "entity_code", "label": "Display Name", "type": "person", "degree": 4521, "x": 12.3, "y": -45.6, "fx": 12.3, "fy": -45.6 }
  ],
  "links": [
    { "source": "entity_code_a", "target": "entity_code_b", "weight": 42 }
  ]
}
```

Note: use `"links"` (not `"edges"`) as the array key — force-graph expects `{ nodes, links }`.

**Console output:** Log DATA_DIR, CURATED_TOP_N, CURATED_MIN_WEIGHT, entity_links count, top entity count, edge count, output file path and size.

**Requires:** `graphology` (0.26.0, installed), `graphology-layout-forceatlas2` (0.10.1, installed). Do NOT require `graphology-metrics` — use the manual degree counting loop from precompute-bipartite-graph.js.
  </action>
