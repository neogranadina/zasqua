Create `src/js/entity-explorer.js` containing a single `EntityExplorer` class. Model it closely after `SearchPage` in `search.js` (NOT `PlaceExplorer`) since it uses Pagefind. Key differences from SearchPage:

**Constructor:**
- Container: `document.getElementById('entity-explorer')`
- `this.perPage = 20`
- Parse `data-entity-types` JSON from container for type label mapping (same pattern as SearchPage's `data-level-labels`)
- State shape: `{ q: '', entity_type: [], primary_function: [], dateFilter: null, sort: '', page: 1 }`
- `this.facetGroupState = { entity_type: true, primary_function: true, date: true }`

**init():**
- Call `this.parseUrlParams()`
- Import from `/pagefind-entities/pagefind.js` (NOT `/pagefind/pagefind.js`)
- Call `await this.pagefind.options({ bundlePath: '/pagefind-entities/' })`
- Call `await this.pagefind.init()`
- Cache `this.globalFilters = await this.pagefind.filters()`
- Register `popstate` listener
- Call `this.search()`

**search():**
- Build `pfFilters` object:
  - `entity_type`: `{ any: this.state.entity_type }` when non-empty
  - `primary_function`: `{ any: this.state.primary_function }` when non-empty
  - `year`: `{ any: this.state.dateFilter.years }` when dateFilter active
- Build `pfSort` from `this.state.sort` (format `field:dir`, e.g. `name:asc`)
- Call `this.pagefind.search(this.state.q || null, { filters, sort })`
- Slice results for current page: `search.results.slice(start, start + 20)`
- Load hits: `await Promise.all(pageResults.map(r => r.data()))`
- Use `search.filters` for scoped facet counts (same as SearchPage)
- Call `this.renderSearchResults(data)`

**renderSearchResults(data):**
- Follow SearchPage's `renderSearchResults` method structure exactly:
  - Build `.search-layout` container
  - Build sidebar (`.search-sidebar`) with heading "Filtros", search input, facet groups
  - Build results column (`.search-results`) with results info bar, results list, pagination
  - Mobile filter toggle button
  - Active filter pills
- Handle states: loading overlay, browse prompt (pre-search), no results, error

**renderResultCard(hit):**
- Per UI-SPEC Entity Result Row Anatomy:
- Row 1: `<div>` containing:
  - `<h3 class="result-title"><a href="{hit.url}">{hit.meta.title}</a></h3>`
  - `<span class="entity-type-badge">{entityTypeLabels[hit.meta.entity_type] || hit.meta.entity_type}</span>`
  - If `hit.meta.date_earliest`: `<span class="result-meta">{date_earliest}{endash}{date_latest}</span>` (use endash \u2013; omit date_latest if same as date_earliest or empty)
- Row 2: `<div>` containing (if function or count present):
  - `<span class="entity-result-function">{hit.meta.primary_function}</span>` (if present)
  - ` \u00B7 ` separator (if both present)
  - `<span class="entity-result-doccount">Asociado a {N} documento(s)</span>` (if count > 0; use `toLocaleString('es-CO')` for number formatting; singular "documento" when count === 1)
- Row 3: `<div class="entity-result-variants">` (if name_variants present):
  - `Tambien conocido como: {variant1}, {variant2}, {variant3}` (max 3, split on `, `)

**renderFacets(filters):**
- Three facet groups (follow SearchPage's `renderFacetGroup` pattern):
  1. "Tipo de entidad" -- `entity_type` filter, checkboxes with counts, labels from `this.entityTypeLabels`
  2. "Funcion principal" -- `primary_function` filter, checkboxes with counts (raw values as labels -- already in Spanish)
  3. "Fecha" -- date drill-down tree (copy SearchPage's `renderDateTree`, `renderDateLevel`, `getYearsForLevel`, `onDateSelect` methods)

**Sort controls:**
- Default: empty string (Pagefind relevance when query present, alphabetical when no query)
- Three buttons: "Nombre" (`name:asc`), "Fecha" (`date:asc`), "Documentos" (`count:desc`)
- Active sort gets `.sort-btn.active` class

**URL state (parseUrlParams / pushUrlParams):**
- Read/write: `q`, `tipo` (entity_type, comma-separated), `funcion` (primary_function, comma-separated), `fecha_nivel`, `fecha_valor` (date drill-down), `orden` (sort), `pagina` (page)
- Use `URLSearchParams` and `history.pushState` (same pattern as SearchPage)

**Browse prompt (pre-search state):**
- Show when no query and no active filters
- Display: `<strong>{totalEntityCount}</strong> entidades en el archivo` (total from globalFilters)
- Hint: "Empieza a escribir para buscar, o explora filtrando por tipo o fecha."
- "Explorar todas" button that triggers `this.pagefind.search(null)` (empty search = all entities)

**Mobile filter toggle:**
- Follow SearchPage's mobile toggle pattern:
  - `<button class="mobile-filter-toggle">Filtrar resultados <span>&#x25BE;</span></button>`
  - Toggle `.sidebar-open` class on sidebar
  - Close button with `<span class="material-symbols-outlined">close</span>` and `aria-label="Cerrar filtros"`

**Loading state:**
- `.search-results.results-loading` class (opacity dim)
- `.search-loading-overlay` + `.search-spinner` centered

**Self-initialisation at bottom of file:**
```javascript
document.addEventListener('DOMContentLoaded', () => {

  if (el) new EntityExplorer(el);
});
```
