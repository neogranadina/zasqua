Refactor `PlaceExplorer` to split data sources: **Pagefind** for search/facets/results list, **place-index.json** for map coordinates only. The map functionality (MapLibre heatmap/circle layers, viewport filtering, moveend listener) stays intact.

**Core architectural change:**

1. **`init()` method** -- Load both data sources:
   - Load Pagefind: `this.pagefind = await import('/pagefind-places/pagefind.js')`, then `await this.pagefind.options({ bundlePath: '/pagefind-places/' })`, then `await this.pagefind.init()`, then `this.globalFilters = await this.pagefind.filters()`
   - Load place-index.json: `this.allPlaces = await (await fetch('/data/place-index.json')).json()` -- for map coordinate data only
   - Both loads can happen in parallel: `await Promise.all([pagefindInit, jsonLoad])`

2. **`search()` method** -- Replace `applyFilters()` with Pagefind search:
   - Build `pfFilters` from state:
     - `place_type`: `{ any: this.state.type }` when non-empty (note: the state key is `type` but the Pagefind filter key is `place_type`)
     - `has_coordinates`: value from `this.state.hasCoords` when not null (Pagefind filter value is string `"true"` or `"false"`)
     - `has_authority`: value from `this.state.hasAuthority` when not null
   - Build `pfSort` from `this.state.sort` (currently `'name'` or `'count'`)
   - Call `await this.pagefind.search(this.state.q || null, { filters, sort })`
   - Slice results for current page
   - Load hits: `await Promise.all(pageResults.map(r => r.data()))`
   - Use `search.filters` for scoped facet counts
   - Call render methods

3. **`renderResults(hits)`** -- Update to render from Pagefind hit objects instead of allPlaces items:
   - Each hit has `hit.url` (link to place page), `hit.meta.title` (place name), `hit.meta.place_type`, `hit.meta.has_coordinates`, `hit.meta.linked_count`, `hit.meta.name_variants`
   - Keep the same result row HTML structure (`.result-item` with name link, type badge, authority pills, linked count)
   - The place result rows currently read fields like `place.display_name`, `place.place_type`, `place.wikidata_id` etc. Update these to read from `hit.meta.*` and `hit.url`

4. **Map stays on place-index.json:**
   - `initMap()` -- Keep as-is, reads from `this.allPlaces` for GeoJSON source
   - `updateMap()` -- Keep as-is, updates GeoJSON source from coordinates
   - The map always shows ALL places (or viewport-filtered subset) regardless of Pagefind search state

5. **Viewport filtering integration:**
   - When `this.state.mapBound` is true, after getting Pagefind results, cross-reference with map bounds
   - Pagefind results include `hit.url` which contains the place slug. Match against `this.allPlaces` coordinates to determine if a result is within the viewport
   - Alternative (simpler): Store a Set of place URLs within viewport from `this.allPlaces`, filter Pagefind hits against it
   - The map's `moveend` listener should trigger a re-render of results (not a new Pagefind search -- just re-filter the existing results by viewport)

6. **Facet rendering** -- Update to use Pagefind filter counts:
   - `renderFacets(filters)` receives the `search.filters` object
   - Place type facet: use `filters.place_type` for counts, `this.placeTypes` for label mapping
   - Has coordinates: use `filters.has_coordinates` counts (values `"true"`, `"false"`)
   - Has authority: use `filters.has_authority` counts

7. **URL state** -- Keep existing URL param names (`q`, `tipo`, `coords`, `authority`, `orden`, `pagina`, `mapa`). Map from URL params to Pagefind filter keys internally.

8. **perPage** -- Change from 50 to 20 to match entity explorer and description search consistency. (Per D-08: same layout as `/buscar/`.)

**What to preserve unchanged:**
- MapLibre map initialisation, layer definitions, heatmap/circle styling
- "Filter by map area" toggle and viewport filtering logic
- Mobile filter toggle pattern
- PMTiles protocol setup
- The `moveend` listener behaviour (updates results list only, not URL -- per Phase 7 decision)

**What to remove:**
- `applyFilters()` method (replaced by Pagefind search)
- In-memory substring search logic
- In-memory facet counting logic
- Any code that reads `this.allPlaces` for search/filtering (keep only for map coordinates)
