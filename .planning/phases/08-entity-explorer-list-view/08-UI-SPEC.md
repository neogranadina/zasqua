## Spacing Scale

Standard 8-point scale used throughout the codebase. All values match the existing `--spacing` base unit of `0.25rem` (4px) established by Tailwind v4.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge internal gaps |
| sm | 8px | Compact element spacing, gap between inline meta items |
| md | 16px | Default element spacing, result-item padding |
| lg | 24px | Section padding, sidebar group spacing |
| xl | 32px | Layout gaps (`.search-layout` gap: 2rem) |
| 2xl | 48px | Major section breaks (`.search-layout` padding: 2rem 0) |
| 3xl | 64px | Page-level spacing |

Exceptions: `.search-sidebar` width is 260px (not a spacing token — a layout dimension). Filter pill internal padding is 4px vertical / 8px horizontal (matches xs/sm). Facet option padding is 3px 0 (sub-grid tolerance — leave as-is from existing code).

**Source:** `main.css` `.search-layout`, `.result-item`, `.facet-group`, `.filter-pill` measurements.

All fonts are loaded from Google Fonts CDN with `display=swap`. Font variables defined in Tailwind `@layer theme`.

| Role | Font | CSS Var / Class | Size | Weight | Line Height |
|------|------|-----------------|------|--------|-------------|
| Body / UI labels | DM Sans | `var(--font-sans)` / `font-sans` | 16px (1rem) | 400 | 1.5 |
| Small meta / badges | DM Sans | `var(--font-sans)` | 13–14px (0.875rem) | 400 | 1.4 |
| Result title | DM Sans | `var(--font-sans)` | 17.6px (1.1rem) | 400 | 1.4 |
| Page title | Cormorant Garamond | `var(--font-display)` / `font-display` | 28px (1.75rem) | 600 | 1.2 |
| Sidebar heading | Crimson Text | `var(--font-serif)` | 24px (1.5rem) | 400 | 1.3 |
| Facet group title | DM Sans | `var(--font-sans)` | 15.2px (0.95rem) | 600 | 1.4 |

**Declared sizes (3 functional tiers):**
1. **14px** — metadata, badges, secondary text (`result-meta`, `result-snippet`, `.variant-tag`)
2. **16px** — body, UI labels, facet options, intro paragraph
3. **17.6px** — result titles (`.result-title`, existing `1.1rem`)
4. **28px** — page heading (`font-display`, `text-[1.75rem]` as used in `lugares.njk`)

**Declared weights (2):** 400 (regular) and 600 (semibold).

**Source:** `main.css` `.result-title`, `.result-meta`, `.facet-group-title`, `.search-sidebar-heading`; `lugares.njk` heading pattern.

## Entity Result Row Anatomy

Each entity result row (`.result-item`) contains the following structure, left to right / top to bottom.

**Row 1 — Name + type badge + date range:**
```
[Entity name link]  [Type badge]  [Date range text]
```
- Entity name: `.result-title > a` linking to `/entidad/{entity_code}/`
- Type badge: `.entity-type-badge` with Spanish label from `ui.entity.types`
- Date range: `0.875rem`, `var(--color-stone-400)`, format "1750–1823", omitted when absent

**Row 2 — Function + doc count:**
```
[Primary function] · [Doc count]
```
- Function: `.entity-result-function`
- Separator: `·` in `var(--color-stone-300)`
- Doc count: `.entity-result-doccount`
- Both omitted when data not present

**Row 3 — Name variants (conditional):**
```
También conocido como: [variant1], [variant2]
```
- Class: `.entity-result-variants`
- Omitted when no variants exist
- Maximum 3 variants shown; additional suppressed with no count indicator

**Source:** `08-CONTEXT.md` D-10; place explorer `renderResults` pattern in `place-explorer.js`.

## Interaction Contract

### Search input
- Input: `.refine-search` (existing rounded pill, stone-50 background)
- Focus state: `border-color: var(--color-burgundy-light)`, `background: #fff`
- Placeholder text: "Buscar entidades..." (Spanish — see Copywriting Contract)
- Debounced on `input` event — no submit button required (Pagefind handles this)

### Facets
- Three facet groups (all collapsible via `.facet-group-toggle`):
  1. **Tipo de entidad** — checkboxes: Persona, Entidad corporativa, Familia
  2. **Función principal** — checkboxes for available function values (counts from Pagefind)
  3. **Fecha** — date drill-down tree (century → decade → year), reusing `.date-tree` pattern
- Facet counts reflect total dataset, not filtered set (per Phase 7 decision D-19, carried forward)
- Checked state: `accent-color: var(--color-burgundy-deep)`

### Sort
- Default: alphabetical by name (`sort_name`) — labelled "Nombre"
- Toggle options: "Fecha" (date_earliest) and "Documentos" (linked description count)
- Active sort: `.sort-btn.active` (stone-900, weight 600)

### Pagination
- Pagefind native pagination — 20 results per page (matches place explorer and description search)
- `.pagination-link.active`: `var(--color-periwinkle)` background

### Mobile
- Sidebar hidden by default; `.mobile-filter-toggle` button appears
- On toggle: sidebar gains `.sidebar-open` — full width, stone-200 background, `border-radius: 24px`
- Filter panel shows close button (Material Symbols `close`)

### Loading state
- `.search-results.results-loading` dims content (opacity 0.3)
- `.search-loading-overlay` + `.search-spinner` (burgundy-deep top border) centred in viewport

### Pre-search (browse prompt)
- `.search-browse-prompt` with entity count: "**92.042** entidades en el archivo"
- Hint text: "Empieza a escribir para buscar, o explora filtrando por tipo o fecha."
- "Explorar todas" button triggers all-entities query (empty Pagefind search)

## Page Structure

```
<nav.breadcrumb>
  Inicio › Explorar entidades

<div.container.font-sans>
  <h1.font-display>Explorar entidades</h1>
  <p.text-stone-600>Intro paragraph</p>

  <div#entity-explorer>
    <!-- Rendered by EntityExplorer JS class -->

    [mobile-filter-toggle button]
    [active-filters pills]

    <div.search-layout>
      <aside.search-sidebar>
        <h2.search-sidebar-heading>Filtros</h2>
        [filter-panel-header] (mobile only)
        <div.refine-search>[search input]</div>
        <div.facet-group> × 3
        [filter-panel-bottom-close] (mobile only)

      <div.search-results>
        <div.search-results-info>
          <span.results-count>N entidades</span>
          <div.sort-wrap>[sort buttons]</div>
        <ul.search-results-list>
          <div.result-item> × 20
        <div.search-pagination>[pagination links]</div>
```

**Note:** No map section — this explorer has no MapLibre component. The `data-pagefind-ignore` attribute must be set on the container `<div>` to exclude the explorer chrome from the description Pagefind index.
