    **Note on filter sync precision:** The Pagefind results only show one page (20 results). For a more complete match, when the explorer dispatches `filter-change`, we can read the total result count. If the query/facets are active, we mark ALL graph nodes as suppressed except those whose entity codes appear in the full Pagefind result set. Since we cannot enumerate all Pagefind results without loading them all, an alternative approach: for each graph node, check if its attributes (type, label) match the active filters. This is an approximation:
    - If `state.entity_type.length > 0`: suppress nodes whose type is not in the list
    - If `state.q`: suppress nodes whose label does not include the query (case-insensitive)
    - This gives a reasonable visual approximation without needing to load all Pagefind results
    - Use this attribute-based approach as the primary filter sync mechanism

    The `syncFilters` implementation should be:
    ```javascript
    syncFilters(state) {
      this.suppressedNodes.clear();
      const hasFilters = state.q || state.entity_type.length > 0 ||
        state.primary_function.length > 0 || state.dateFilter;

      if (!hasFilters) {
        this.sigma.refresh();
        return;
      }

      this.graph.forEachNode((node, attrs) => {
        let dominated = false;
        if (state.entity_type.length > 0 && !state.entity_type.includes(attrs.type)) {
          dominated = true;
        }
        if (state.q && !attrs.label.toLowerCase().includes(state.q.toLowerCase())) {
          dominated = true;
        }
        if (dominated) this.suppressedNodes.add(node);
      });

      this.sigma.refresh();
    }
    ```
