<decisions_made>

- Co-occurrence graph scrapped — bipartite document-entity graph instead. Documents are the point of archival relationships, not invisible edges.
- Entity detail page is primary graph home, not the explorer. Ego-network from one entity is legible.
- Graph builds from entity-link shards on demand — 90K shards already exist from Phase 4.
- Click-to-expand uses desc-entity-lookup.json (88K entries, 5.7MB, loaded once on first click) + Pagefind entity index for display names.
- Timeline/graph toggle embedded in natural language sentence, not widget tabs.
- Entity detail layout flipped to 35/65 — timeline is the main content.
- Default explorer sort: count:desc (most linked entities first).
