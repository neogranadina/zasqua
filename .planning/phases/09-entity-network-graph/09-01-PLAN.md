    **Step 3: Refactor the edge-pair emission loop to track role pairs.**
    Create a separate `edgeRolePairs` Map alongside `edgeWeights`. In the pair loop, deduplicate by `{ code, role }` tuples (not just codes — an entity can appear in the same description with different roles). For each pair, compute a normalised role-pair key by sorting the two roles alphabetically and joining with `|` (e.g. `"creator|subject"`). Accumulate counts in `edgeRolePairs`.

    ```javascript
    const edgeRolePairs = new Map();

    for (const [, entries] of byDescription) {
      // Deduplicate by code (but keep all role variants)
      const uniqueByCode = new Map();
      for (const e of entries) {
        if (!uniqueByCode.has(e.code)) uniqueByCode.set(e.code, []);
        uniqueByCode.get(e.code).push(e.role);
      }
      const codes = Array.from(uniqueByCode.keys());
      if (codes.length < 2) continue;

      for (let i = 0; i < codes.length; i++) {
        for (let j = i + 1; j < codes.length; j++) {
          const a = codes[i] < codes[j] ? codes[i] : codes[j];
          const b = codes[i] < codes[j] ? codes[j] : codes[i];
          const edgeKey = `${a}|${b}`;
          edgeWeights.set(edgeKey, (edgeWeights.get(edgeKey) || 0) + 1);

          // Role pairs: combine all roles of entity a with all roles of entity b
          if (!edgeRolePairs.has(edgeKey)) edgeRolePairs.set(edgeKey, {});
          const pairs = edgeRolePairs.get(edgeKey);
          const rolesA = uniqueByCode.get(codes[i] < codes[j] ? codes[i] : codes[j]);
          const rolesB = uniqueByCode.get(codes[i] < codes[j] ? codes[j] : codes[i]);
          for (const rA of rolesA) {
            for (const rB of rolesB) {
              const rpKey = [rA, rB].sort().join('|');
              pairs[rpKey] = (pairs[rpKey] || 0) + 1;
            }
          }
        }
      }
    }
    ```

    Also update `byEntity` counting to work with the new object format — count by `e.code` instead of bare entity code.

    }
    for (const edge of filteredEdges) {

      }

    const settings = forceAtlas2.inferSettings(layoutGraph);

    for (const node of nodes) {

      node.x = attrs.x;
      node.y = attrs.y;
    }
